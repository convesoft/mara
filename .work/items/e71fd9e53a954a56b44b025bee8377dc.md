## Defect and impact
Transitive path provenance eagerly derives reachable supporting edges for every endpoint pair, repeatedly scanning Cartesian pairs. Each new page recomputes it, even with one selected root or an empty selection. In a native Linux debug build, a 150-item parent chain took approximately 28 seconds for one-root parent+ execution with max_rows=1/limit=1; the title query on the same sources took under 0.1 seconds. Empty selection exceeded the review probe's 20-second timeout. These are observations, not a controlled benchmark or a new product latency threshold. The path query finishes within the subsequent 45-second probe; its exit-1 row-budget response is expected incomplete execution, not a crash or loss of facts.

## Expected outcome
Derive finite canonical supporting edges only for participating queried endpoint pairs, or otherwise avoid unnecessary whole-corpus closure. Preserve admitted standard SELECT/path semantics, cyclic/diamond provenance, authored occurrences, exact typed bindings and deterministic continuation. Do not replace the proven backend, introduce a query DSL, deadline service, benchmark framework or new host adapter.

## Deferral
Accepted actionable but unscheduled performance improvement, outside the selected task's current acceptance. That acceptance requires valid named definitions, typed source-linked facts, empty roots, malformed/unavailable distinctions, bounded record/byte continuation and real Rust/embedded CLI/MCP execution. DES-QUERY-INPUT-RESULT-CONTRACT explicitly bounds observed rows, not graph work, deadline or memory; no accepted workload/latency gate is violated. The concrete primary fixtures pass and the finite path query terminates with correct available facts. No data-loss risk, exploit or unusable release is demonstrated. The timeout is the review probe's chosen bound, not an accepted support promise. The current task remains open pending separately authorized integration; this entry neither waives a correctness failure nor schedules optimization. Report the cost as a known limitation rather than silently claiming uniformly cheap bounded pages.
