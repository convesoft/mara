## Outcome
Deliver foreground run, detached background start, stop/status and selected-project force refresh with safe per-user endpoint ownership and deliberate local HTTP connection-info handoff.

## Acceptance
- [x] Real foreground/background lifecycle works; only one instance owns the user endpoint, a second start reports it, consumer disconnects do not stop it, and no OS service or automatic startup is introduced.
- [x] Stale endpoint handling never stops an unrelated process; stop/restart discards only memory caches and leaves source/recovery data usable.
- [x] Selected-project refresh invalidates derived state even for unchanged inputs. Configured indexers run from the selected root using the daemon startup environment; restart adopts changed environment.
- [x] Provide the local connection-info command/private handoff boundary and an explicit unavailable result while HTTP is disabled; the dependent HTTP task wires the enabled endpoint/token. Routine status/logs omit tokens, and credentials are not placed in URLs or project files.
- [x] Run process-level lifecycle/refresh/ownership regressions in isolated runtime/Git/configuration state and document actual command/options behavior.
