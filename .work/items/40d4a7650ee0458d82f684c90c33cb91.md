## Outcome
Introduce the high-level native client and make CLI/MCP thin adapters to it, preserving caller-context project selection and safe pre-dispatch backend choice.

## Acceptance
- [ ] Support direct, default auto and daemon-required modes, with explicit library options/CLI flags overriding matching environment settings and no persisted preference/configuration format or daemon auto-start.
- [ ] Resolve nearest-project/explicit/bound MCP selection and initialization targets in caller context before dispatch; absolute request selection and bound-MCP override refusal remain compatible.
- [ ] Auto falls back only for established absence or incompatibility before dispatch. Domain/authentication/other connection errors never trigger fallback, and required mode reports unavailable/incompatible daemons.
- [ ] A lost dispatched mutation response produces a typed actionable unknown-outcome error directing source/recovery inspection, without retry, backend replay or rollback claims.
- [ ] Run real Rust client, CLI and stdio MCP reads/mutations/validation/trace/continuation through both backends, preserving owning formats and selection behavior.
