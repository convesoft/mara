## Outcome
Implement the real per-user native operation server and IPC transport using the runtime directly, with one reusable JSON-RPC 2.0 protocol for later HTTP adaptation.

## Acceptance
- [ ] Use same-user Unix sockets and private per-user runtime discovery/session state on supported Linux/macOS hosts; endpoint state never becomes project content.
- [ ] Negotiate Mara protocol version 1 and exact application-version compatibility before project operations, reporting supported result formats and backend capabilities.
- [ ] Dispatch the complete native operation surface into isolated reconciled runtime sessions, never recursively through the auto client. Validation-invalid domain results remain distinct from RPC/operation failures.
- [ ] Exercise real IPC reads, guarded writes, continuation and multiple project roots with actionable sanitized failures; define requests/results/errors in canonical Mara interface knowledge.
- [ ] The running server foundation remains independent of individual consumer disconnects; local lifecycle management is completed by the sibling lifecycle task.
