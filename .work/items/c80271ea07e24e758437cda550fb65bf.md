## Outcome
Add the shared reconciled session implementation for long-lived embedded clients and the daemon, retaining disposable bounded memory projections without persisted indexes.

## Acceptance
- [x] Canonical project roots key isolated sessions; separate Git worktrees never share project state through their common Git directory.
- [x] Reconcile effective inventory/content, configuration, schema, rules, ignore and recorded code inputs before every operation; successful, failed and rolled-back writes invalidate affected state, and invalid current inputs cannot yield stale success.
- [x] Unchanged inputs reuse parsing/discovery/relations/compiled rules and eligible code indexes; command/input/grammar/query changes invalidate code reuse, preserving empty-language activation and indexer failures.
- [x] Force refresh discards derived state even for unchanged recorded files. Idle retention is bounded without evicting in-flight state, and restart/eviction preserves canonical source and cursor/handle contracts.
- [x] Targeted real-runtime tests prove freshness and reuse with observable parse/indexer activity; document explicit external-input refresh and startup-environment limitations.
